
# Bolonha e Milano

Jogo de estrategia economica medieval desenvolvido em Java 17.

## Etapas desenvolvidas

### Etapa 1
- Classe Main.
- Classe Menu.
- Menu interativo.

### Etapa 2
- Classe Jogador.
- Classe Cidade.
- Cadastro do jogador e cidade.
- Status da cidade.

### Etapa 3
- Sistema de economia.
- Florins, terras e graos.
- Classe Mercado.
- Compra e venda de graos.
- Compra e venda de terras.
- Validacao dos recursos.

## Estrutura

- src/bolonhaemilano/: codigo Java.
- uml/: diagramas de classes.
- casos-de-uso/: diagramas de casos de uso.

## Como compilar

javac -encoding UTF-8 -d bin src/bolonhaemilano/*.java

## Como executar

java -cp bin bolonhaemilano.Main
